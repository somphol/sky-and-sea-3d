## YouTube embeds

The optional long-form music panel embeds YouTube players using
`youtube-nocookie.com`. Video availability, regional restrictions and playback
are controlled by YouTube. This project does not host or redistribute any
music or video content.

## Web Audio API

The ambient soundscape, wind chimes and timer chimes are synthesized at runtime
with the browser's native Web Audio API. No audio files are downloaded.
